# SelectionTranslator v0.2.0 核心架构规范

> 目标：低耦合、强扩展、易维护、易二开  
> 适用：v0.2.0 及后续版本

## 1. 总体架构

采用轻量化：

**Ports & Adapters + Registry + Event-driven Orchestration**

不引入重型 DDD 框架。

职责：

```text
Domain      定义业务对象和规则
Registry    定义系统里“有哪些能力”
Service     编排业务流程
Adapter     实现外部协议
Platform    提供 Windows/Tauri 系统能力
UI          只调用 Application Service
```

目标：

- 新增 Provider 不改 Selection；
- 新增 Action 不改 Provider；
- 新增 Trigger 不改 AI Runtime；
- 新增设置页不改 Settings Shell；
- 新增系统能力不侵入业务核心；
- 二开尽量通过注册和 Adapter 完成。

---

## 2. 强制依赖方向

```text
UI
 ↓
Application Service
 ↓
Domain / Registry
 ↓
Port
 ↓
Adapter / Platform
```

禁止：

```text
Provider Adapter → ResultWindow
Selection Engine → Provider Adapter
Toolbar → Credential Store
Prompt → Tray
Tray → OpenAI Adapter
Settings UI → reqwest
Action Registry → Windows Hook
Credential Store → React
```

模块只能通过：

- Domain types；
- Service interfaces；
- Registry；
- Events；
- Ports。

禁止跨层直接 import 内部实现。

## 5. Provider Profile

Provider Profile 表示用户的一条渠道配置。

```ts
export interface ProviderProfile {
  id: string
  name: string
  adapterId: string
  apiBase: string
  credentialId?: string
  defaultModel?: string
  enabled: boolean
  defaults?: GenerationOptions
  extra?: Record<string, unknown>
}
```

示例：

```json
{
  "id": "provider-openrouter-main",
  "name": "OpenRouter 主线路",
  "adapterId": "openai-chat",
  "apiBase": "https://openrouter.ai/api/v1",
  "credentialId": "provider-openrouter-main",
  "defaultModel": "anthropic/claude-sonnet",
  "enabled": true
}
```

必须区分：

```text
Provider Profile = 用户的一条渠道
Protocol Adapter = 协议实现
```

例如：

```text
OpenRouter      ┐
AnyRouter       ├─ openai-chat adapter
自建中转        ┘
Anthropic Official ─ anthropic adapter
Gemini Official    ─ gemini adapter
```

新增 OpenAI-compatible 中转不应新增 Rust 协议实现。

## 6. Credential Store

普通配置永远不保存 API Key。

配置只保存：

```text
credentialId
```

Credential Manager：

```text
SERVICE = SelectionTranslator
ACCOUNT = provider:<provider-id>
```

例如：

```text
provider:provider-openrouter-main
provider:provider-anyrouter
provider:provider-gemini-official
```

所有 Secret 通过 Credential Port 获取。

---

## 7. Provider Adapter

推荐 Rust：

```rust
pub trait ProviderAdapter: Send + Sync {
    fn id(&self) -> &'static str;
    fn capabilities(&self) -> ProviderCapabilities;

    fn build_stream_request(
        &self,
        client: &reqwest::Client,
        ctx: &ProviderContext,
        input: &AiInput,
    ) -> Result<reqwest::RequestBuilder, ProviderError>;

    fn parse_stream_event(
        &self,
        bytes: &[u8],
    ) -> Result<Option<AiChunk>, ProviderError>;

    async fn list_models(
        &self,
        client: &reqwest::Client,
        ctx: &ProviderContext,
    ) -> Result<Vec<ModelInfo>, ProviderError>;
}
```

Adapter 不允许：

- 访问 Toolbar；
- 访问 ResultWindow；
- 读取 React state；
- 读取全局 Provider 设置；
- 直接读取 Credential Store；
- 决定 fallback。

所有上下文由上层注入。

## 8. Provider Registry

统一注册：

```rust
registry.register(OpenAiChatAdapter::new());
registry.register(AnthropicAdapter::new());
registry.register(GeminiAdapter::new());
```

执行：

```text
adapterId
  ↓
ProviderRegistry
  ↓
ProviderAdapter
```

禁止业务层反复出现：

```rust
match adapter {
    OpenAI => ...
    Anthropic => ...
    Gemini => ...
}
```

协议分支只允许集中在 bootstrap / registry / migration 边界。

## 12. Route Service

Route Service 负责：

1. 接收 `actionId`；
2. 找到 ActionRoute；
3. 解析 ProviderProfile；
4. 获取 Credential；
5. 选择 Adapter；
6. 启动 primary request；
7. 根据结构化错误决定 fallback。

Route Service 不负责：

- UI；
- Selection detection；
- Prompt 编辑；
- Window lifecycle。

---

## 13. Fallback Policy

允许 fallback：

- connect failed；
- timeout；
- HTTP 408；
- HTTP 425；
- HTTP 429；
- HTTP 500 / 502 / 503 / 504；
- empty output。

禁止 fallback：

- 已输出部分内容；
- 用户 cancel；
- 401 / 403；
- validation error；
- 配置错误。

Fallback Policy 独立模块，禁止写在 ResultWindow `catch` 中。

## 19. Selection Engine 边界

```text

→ Gesture Detect
→ Text Resolve
→ SelectionEvent
```

- 翻译；
- Action Route；
- Provider；
- Model；
- Prompt；
- Settings UI。

```ts
export interface SelectionEvent {
  text: string
  sourceApp: string
  method: 'uia' | 'accessibility' | 'clipboard'
  trigger: string
  anchor: {
    x: number
    y: number
```

## 24. 结构化错误

逐步替换 `Result<T, String>`：

```rust
pub enum AppError {
    Validation,
    Provider,
    Network,
    Credential,
    Selection,
    Platform,
    Storage,
}
```

前端：

```ts
export interface AppErrorDto {
  code: string
  message: string
  retryable: boolean
  detail?: string
}
```

Provider error code：

```text
PROVIDER_AUTH_FAILED
PROVIDER_RATE_LIMITED
PROVIDER_TIMEOUT
PROVIDER_UNAVAILABLE
PROVIDER_INVALID_RESPONSE
PROVIDER_STREAM_INTERRUPTED
MODEL_NOT_FOUND
```

Fallback 只能依赖 code/category，不解析错误文案。

## 26. 八条长期原则

1. **Selection 只负责选中文本，不关心 AI。**
2. **Action 只描述用户要做什么，不绑定具体协议。**
3. **Route 决定 Action 使用哪个 Provider / Model。**
4. **Provider Profile 保存渠道，Adapter 只实现协议。**
5. **UI 只调用 Service，不越层操作网络和平台。**
6. **系统能力通过 Platform Port 暴露。**
7. **扩展优先 Registry，不优先修改核心 switch。**
8. **配置永远可迁移，Secret 永远独立保存。**

如果新功能违反其中两条以上，应先调整架构，而不是继续补丁式实现。
